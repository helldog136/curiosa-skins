# Éditorial papier

Une page de magazine ou de livre : du papier, de l'encre, de belles lettres, des filets fins.

**Pour qui ?** Pour un blog, un journal de bord, un site où l'on aime lire. Le texte passe avant tout.

## Ce que ce skin change

- Les couleurs : un papier crème et une encre brun-noir, avec un rouge « encre rouge » pour les liens et les petits détails. Le mode sombre, appelé « encre », garde la même chaleur (fond brun très foncé, texte ivoire, accent doré).
- Les lettres : un serif élégant (Cormorant Garamond pour les titres, Source Serif pour le texte). Les grands titres sont en italique, les titres de section en capitales espacées.
- La mise en page : une colonne de lecture étroite et centrée, de grandes marges. La marque est centrée en haut, le menu est en ligne sous un double filet.
- Les listes : de simples lignes séparées par des filets, avec une petite vignette à droite.
- Aucune ombre, aucun arrondi. La première lettre d'un texte est agrandie (lettrine).

## Ce que ce skin ne change pas

Aucun texte, aucun lien, aucun bouton n'est ajouté, retiré ou déplacé dans le code : seul l'aspect change. Vous pouvez changer de skin quand vous voulez, sans rien perdre.

## Clair et sombre

Le skin suit le mode de l'appareil, et le public peut choisir « Clair », « Sombre » ou « Automatique » avec la petite bascule du menu.

## Polices et images

Elles sont dans le skin (rien n'est chargé depuis un autre site). Licences : voir `LICENSES/` (polices : SIL Open Font License 1.1 ; texture de papier : domaine public).

## Côté technique

Skin au format du contrat 1 de Curiosa (`skin.json`, `tokens.json`, `skin.css`). Contrôle : `npm run skin:check -- skins/editorial-papier` depuis le cœur de Curiosa. Licence du skin : MIT (fichier `LICENSE`).
