# Curiosa (overlay) / Curiosa overlay

Skin d'overlay pour Curiosa (cœur 0.47.0 ou plus) : il habille les pages d'overlay pour OBS, jamais le site public. Aucun programme ni image : des couleurs, des formes, des décorations et 4 polices libres embarquées (licences dans `LICENSES/`).
*Overlay skin for Curiosa (core 0.47.0 or later): it restyles the OBS overlay pages, never the public site. No program, no image: colours, shapes, decorations and 4 embedded open-licence fonts (licences in `LICENSES/`).*

Jumeau d'overlay du skin de site Curiosa : cabinet de curiosités crème et nuit d'encre, laiton, terracotta et sauge, cartes en tiroir.
*Overlay twin of the Curiosa site skin: a cabinet of curiosities in cream and ink night, brass, terracotta and sage, drawer-style cards.*

**Jumeau du skin de site Curiosa** (`curiosa`) : mêmes couleurs, même ambiance, mêmes formes de base et **mêmes polices** que le site (Fraunces, Instrument Sans, JetBrains Mono, les mêmes fichiers), pour que vos overlays OBS ressemblent à votre site. Il demande le cœur **0.47.0** ou plus (polices dans un skin d'overlay) et déclare le skin de site dont il est le jumeau (`twinOf`).
***Overlay twin of the Curiosa site skin** (`curiosa`): same colours, same mood, same basic shapes and **the same fonts** as the site (Fraunces, Instrument Sans, JetBrains Mono, the very same files), so your OBS overlays look like your site. It needs core **0.47.0** or later (fonts in an overlay skin) and names the site skin it is the twin of (`twinOf`).*

Installation : onglet **Skin** d'une page d'overlay, « Obtenir d'autres skins ».
*Install: the **Skin** tab of an overlay page, "Get more skins".*
