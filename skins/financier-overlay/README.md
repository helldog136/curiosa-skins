# Financier (overlay) / Trading desk overlay

Skin d'overlay pour Curiosa (cœur 0.9.0 ou plus) : il habille les pages d'overlay pour OBS, jamais le site public. Aucun programme, ni police, ni image : des couleurs, des formes, des décorations et les polices du système.
*Overlay skin for Curiosa (core 0.9.0 or later): it restyles the OBS overlay pages, never the public site. No program, no font, no image: colours, shapes, decorations and system fonts.*

Jumeau d'overlay du skin de site Financier : page blanche, titres à empattements fins, surligneur citron et noir profond.
*Overlay twin of the Trading desk site skin: white page, fine serif headings, a lime highlighter and deep black.*

**Jumeau du skin de site Financier** (`financier`) : mêmes couleurs, même ambiance, mêmes formes de base, pour que vos overlays OBS ressemblent à votre site. Le skin de site n'embarque aucune police (pile du système) : le jumeau reprend la même pile et n'a donc aucune police à embarquer. Il déclare le skin de site dont il est le jumeau (`twinOf`, utile dès le cœur 0.47.0 ; sans effet avant).
***Overlay twin of the Trading desk site skin** (`financier`): same colours, same mood, same basic shapes, so your OBS overlays look like your site. The site skin ships no font (system stack): the twin takes the very same stack, so it has no font to embed. It names the site skin it is the twin of (`twinOf`, used from core 0.47.0; ignored before).*

Installation : onglet **Skin** d'une page d'overlay, « Obtenir d'autres skins ».
*Install: the **Skin** tab of an overlay page, "Get more skins".*
