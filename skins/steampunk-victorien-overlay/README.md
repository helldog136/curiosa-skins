# Steampunk victorien (overlay) / Victorian steampunk overlay

Skin d'overlay pour Curiosa (cœur 0.9.0 ou plus) : il habille les pages d'overlay pour OBS, jamais le site public. Aucun programme, ni police, ni image : des couleurs, des formes, des décorations et les polices du système.
*Overlay skin for Curiosa (core 0.9.0 or later): it restyles the OBS overlay pages, never the public site. No program, no font, no image: colours, shapes, decorations and system fonts.*

Jumeau d'overlay du skin de site Steampunk victorien : bois sombre et cuir, laiton, cuivre, plaques à coins coupés.
*Overlay twin of the Victorian steampunk site skin: dark wood and leather, brass, copper, plates with cut corners.*

**Jumeau du skin de site Steampunk victorien** (`steampunk-victorien`) : mêmes couleurs, même ambiance, mêmes formes de base, pour que vos overlays OBS ressemblent à votre site. Un skin d'overlay ne peut pas embarquer de polices : il reprend la pile de polices du site, sans les polices que le site fournit lui-même.
***Overlay twin of the Victorian steampunk site skin** (`steampunk-victorien`): same colours, same mood, same basic shapes, so your OBS overlays look like your site. An overlay skin cannot ship fonts: it takes the site's font stack, without the fonts the site ships itself.*

Installation : onglet **Skin** d'une page d'overlay, « Obtenir d'autres skins ».
*Install: the **Skin** tab of an overlay page, "Get more skins".*
