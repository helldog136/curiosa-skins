# Nef de braise (overlay) / Ember nave overlay

Skin d'overlay pour Curiosa (cœur 0.9.0 ou plus) : il habille les pages d'overlay pour OBS, jamais le site public. Aucun programme, ni police, ni image : des couleurs, des formes, des décorations et les polices du système.
*Overlay skin for Curiosa (core 0.9.0 or later): it restyles the OBS overlay pages, never the public site. No program, no font, no image: colours, shapes, decorations and system fonts.*

Jumeau d'overlay du skin de site Nef de braise : obsidienne, braise, rouge sang et or terni, capitales espacées d'une nef gothique.
*Overlay twin of the Ember nave site skin: obsidian, embers, blood red and tarnished gold, spaced capitals of a gothic nave.*

**Jumeau du skin de site Nef de braise** (`nef-de-braise`) : mêmes couleurs, même ambiance, mêmes formes de base, pour que vos overlays OBS ressemblent à votre site. Le skin de site n'embarque aucune police (pile du système) : le jumeau reprend la même pile et n'a donc aucune police à embarquer. Il déclare le skin de site dont il est le jumeau (`twinOf`, utile dès le cœur 0.47.0 ; sans effet avant).
***Overlay twin of the Ember nave site skin** (`nef-de-braise`): same colours, same mood, same basic shapes, so your OBS overlays look like your site. The site skin ships no font (system stack): the twin takes the very same stack, so it has no font to embed. It names the site skin it is the twin of (`twinOf`, used from core 0.47.0; ignored before).*

Installation : onglet **Skin** d'une page d'overlay, « Obtenir d'autres skins ».
*Install: the **Skin** tab of an overlay page, "Get more skins".*
